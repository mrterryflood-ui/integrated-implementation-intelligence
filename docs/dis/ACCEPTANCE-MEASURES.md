# DIS acceptance measures and benchmark
All targets are PROPOSED thresholds for controlled evaluation, not achieved performance.

| Metric | Method | Proposed initial threshold |
|---|---|---|
| Unsupported material claim escape | Independent passage-level adjudication | 0 in high-stakes public reports |
| Citation exactness | Claim-to-source sample and contradiction audit | >=95% supported; all consequential claims adjudicated |
| Authorization-scope breach | Mutation/negative testing from simulated council approvals | 0 |
| Omitted critical dissent | Compare independent review records with synthesis | 0 material exclusions |
| Unwarranted causal/regulatory certainty | Red-team and golden examples | 0 |
| Missing-question identification | Human-constructed blind spot gold set | Recall >=80%, no false claims of completeness |
| Time-to-useful-answer | Instrumented task study | Baseline first; no universal target without pilot |
| End-user task completion | Observed scenario tasks and accessibility check | Baseline first, improve over comparator |
| Buyer/funder adoption | Real pilot and procurement discovery | Not measurable until engagement |
| Economic sustainability | Full costs, renewals, hosting, human review, support | Positive contribution after validated adoption assumptions |
| Transferability | Re-test across grant, healthcare, software, governance | Performance not materially worse without justified domain-specific adaptations |

Test protocol: identical source access and questions for DIS and comparator; independent second-runtime output; blinded scoring where available; publication of raw model/source traces (redacted for privacy); user consent for external actions. No fabricated benchmark performance.
