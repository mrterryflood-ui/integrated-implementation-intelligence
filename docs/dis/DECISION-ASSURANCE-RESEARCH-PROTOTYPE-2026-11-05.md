# DIS Decision Assurance Lab — Research Stage 1

Date: 2026-11-05
Status: **RESEARCH PROTOTYPE; NOT SCIENTIFICALLY VALIDATED; NEVER AUTHORIZES ACTION**

## Purpose
A bounded, deterministic, inspectable decision-validity layer inside the existing DIS platform. It tests whether typed evidence metadata can expose invalid measurement pooling, delayed or mislocated observations, shared provenance, response-induced measurement distortion, unsupported causal/outcome claims, unworkable triggers, obsolete objectives and incomplete post-success stewardship.

This is not a new persona platform, live sensor-fusion service, clinical instrument, autonomous operational warning, causal estimator, or predictor. It reuses the existing Council philosophy and prior source contracts. Its local browser form makes no outbound model requests, database writes, purchases, external submissions, autonomous decisions or cross-tenant transfers.

## Read-only reuse report
- **Existing / reused:** Council methodology and historical/contemporary educational lenses, answer-release evidence controls, canonical implementation doctrine, RPLICE private partner adapter.
- **Extended:** Existing homepage navigation with a clear research-stage decision lab link.
- **New:** Independent deterministic evidence preflight library; twelve synthetic research-vignette packets; unit and negative tests; one editable research route with accessible local inputs.
- **Not touched:** Partner API, credentials, private records, Clerk permissions, production databases, council authorization, RPLICE checkpoint endpoints, or deployment configuration. No Copilot or paid Replit.
- **Environment:** GitHub source of truth; separate research branch; existing platform tests, TypeScript check, build and browser CI.

|---|---|---|
| F01 | Upstream observation assigned to downstream | SCOPE_MISATTRIBUTION |

| F03 | Incompatible constructs averaged | INCOMPATIBLE_CONSTRUCTS |
| F04 | Disjoint geographic footprints | SCOPE_ALIGNMENT_UNVERIFIED |

| F06 | Advisory changes traffic proxy | MEASUREMENT_REACTIVITY |
| L01 | Changing eligibility denominator | DENOMINATOR_BREAK |
| L02 | Completion without sustained resources or owner | SUCCESS_NOT_SUSTAINMENT |
| L03 | Removed core intervention function | CORE_FUNCTION_UNTESTED |
| L04 | Reward changes reporting or proxy metrics | METRIC_INCENTIVE_SHIFT |
| L05 | Circumstances/values make old goal questionable | REOPEN_OBJECTIVE |
| L06 | Unsupported numerical value of more research | UNSUPPORTED_INFORMATION_VALUE |

Additional tests check unverified timestamps, stale inputs only against explicitly supplied validity windows, shared source origins, hypothetical persona data, absence of claims based on multiple metrics merely counted, and human-review requirements.

## Fail-closed and scientific boundaries
- HOLD_UNSUPPORTED_CLAIM denotes an unsupported **inference**, not an instruction to delay domain-authorized urgent safety responses.
- HUMAN_REVIEW_REQUIRED is never interpreted as evidence validity, approval, efficacy or operational readiness.
- Every result has scientificValidation=NOT_ESTABLISHED and actionAuthorized=false, including packets with no coded findings.
- Eight lenses are declared **analytical prompts**, not testimony, representation, endorsements or independent data from actual people.
- No aggregate truth score, universal confidence metric, uniform freshness time, or automatic source independence is inferred.
- The forms are entirely local and ask for descriptive nonpersonal examples. Do not enter sensitive records.
- Passing all twelve author-constructed synthetic cases is engineering verification, NOT a validated sensitivity, specificity, calibration, improvement in real-world decisions or independent scientific study.

## What still must happen before scientific/operational claims
Independent methods panel, case/metric validity audit, ethics determination if appropriate, predeclared study design, blinded external reviewers, comparison against capable current practice plus existing established methods, real-world feasibility, negative-effect measurement, and a decision-value and burden assessment. Unfavorable results are permitted and should change or end the design.
