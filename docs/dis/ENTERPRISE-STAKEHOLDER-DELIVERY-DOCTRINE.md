# Enterprise stakeholder-delivery doctrine — proposed shared contract

This is a cross-domain standard for DIS and every owned platform, not an AIDE-only feature. A repository file is not evidence that all applications enforce it.

## MAP–GAP, collaboration, execution and measurement
1. Identify the actual assignment, requester, audience, authority, decisions and due date.
2. Inspect the specific system, original correspondence, current serving revision, tests and existing work. Do not substitute portfolio memory.
3. Map verified facts, conflicting claims, assumptions, unknowns, data rights, and missing evidence.
4. Investigate gaps with source-level receipts. Never silently turn missing data into zero.
5. Assemble the appropriate discipline-specific council; label simulated lenses separately from verified human participation.
6. Red-team evidence, security, feasibility, costs, unintended effects, equity and operational reality. Request an external human SME prospectus when expertise is absent; hiring, outreach and compensation require approval.
7. Co-design architecture, service journeys, responsibilities, risks, milestones, budgets and implementation measures with stakeholders.
8. Generate editable one-pager, slides, technical design, source register, implementation plan, measures and decision log. Every material claim must have an inspectable source and an evidence status.
9. Obtain the human's selected autonomy and approvals. Approval for a task does not transfer private tenant data or grant another platform's permissions.
10. Execute only authorized operations, record results, test against acceptance criteria, assess fidelity and outcomes, and revise.

## Cross-platform acceptance
Each integration must show its canonical source and production revision, scoped identity, correct operation and response, positive and negative authorization tests, tenant isolation, accessible desktop/mobile journey, source traceability, owner-approved deployment, recovery and measured outcome where claimed.

## Design requirements
Photorealistic imagery must be properly licensed or clearly labeled synthetic; never portray illustrative people as real VA patients or actual findings. All gauges and meters require metric definitions, denominators, data vintage, source, thresholds and uncertainty; unknown metrics show 'not measured' rather than fabricated values. Support accessible, human-centered, bilingual initial workflows and team review of editable artifacts.

## Non-negotiable truth states
PLANNED != CODED != TESTED != MERGED != DEPLOYED != AUTHENTICATED != INTEGRATED != VALIDATED != MEASURED. A green build cannot upgrade a claim.
